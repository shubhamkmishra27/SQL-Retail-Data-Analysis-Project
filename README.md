# 📊 SQL Case Study Project – Customer & Sales Analysis

## 👨‍💻 About Project
This is an end-to-end SQL data analysis case study where I worked on a retail database containing Customers, Orders, Products, Suppliers, and Order Items data.

The project focuses on extracting business insights using SQL queries, joins, subqueries, aggregations, views, and stored procedures.

## 🛠️ Tools & Skills Used
- SQL (SQL Server)
- Joins (INNER, LEFT, RIGHT)
- Subqueries
- Aggregate Functions
- Group By & Having
- Views & Stored Procedures
- Data Cleaning & Filtering
- Business Data Analysis

## 🗂️ Database Tables Used
- Customer
- Orders
- OrderItem
- Product
- Supplier

## 📌 Key Business Problems Solved
- Customer analysis by country  
- Total sales amount by each customer  
- Top 10 most expensive products  
- Monthly sales analysis (2013)  
- Customers without orders  
- Suppliers without fax numbers  
- Top customers per country by sales  
- Products above average price
